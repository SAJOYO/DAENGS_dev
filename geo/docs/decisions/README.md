확정된 것만. 어느 갈래에서 나왔는지 링크. 갈래 파일은 `../explorations/`에 그대로 남긴다.
결정은 당시의 판단을 지우지 않는다. 뒤 결정이 현재 제품 범위를 바꾸면 이전 구현은 코드에

## 결정 #51 이후 현재 범위

- **코어 유지**: `geo/search`, `place`·`ingest`, 영업시간 판정, provider 경계와 Usage Gate,
  단발 `/journey`, 프로필 계약, Android 위치→검색→지도 셸, `WalkFacts` outbound 계약
- **구현은 있으나 parked**: 자연어 refine/LLM, 병원 suggested actions. 다시 채택하기 전까지 제품 차별점이나 다음 구현 순서로 세지 않는다
- **기각(구현 제거)**: 커뮤니티 근거·근거 인덱스·홈페이지 추출 (#63), 과목 축과 카카오
  카테고리 보강 (#64), 도보 옵션 fan-out·시설 점수·계단 advice (#66). 갈래 문서는 남기고 코드는 없앴다
- **산책 구현됨**: 서버 세션 API·원순서 fix·`WalkFacts`·정지/시설 occurrence·원좌표 purge,
  Android foreground service·Room 영속 저장·종료 후 서버 업로드 (에뮬레이터 관통 확인)
- **아직 미구현**: process-death 복구와 stale OPEN 세션 TTL, 업로드 재시도·주기,
  로컬 원본을 포함한 위치 프라이버시 정책·삭제 UI, 인증/접근 통제
