# dev 콘솔 + spots (2026-08-19)

`GET /dev` — 검증용 한 장(HTML 1파일, Leaflet+OSM, 앱 UI 아님). 필터 칩=`edits`, 텍스트=`utterance`, 카드 클릭=`with_polyline_for`.

## 왜 달았나
JSON으로는 루프(말→조건→화면)의 감각과 "이 길이 어떤 길인지"가 안 보였다. 올려보니 바로 3개 잡힘:
1. `도착 — 도착 근처` — TMAP이 endName을 nearPoiName에 넣음 → 필터
2. 같은 노트("큰길 — 목줄 짧게…")가 횡단보도마다 반복 → 같은 (종류,도로) 첫 번째만 풀 노트
3. `테헤란로 횡단보도 ×4` — 실은 테헤란로를 *따라* 걸으며 골목을 건너는 것. **TMAP은 무슨 길을 건너는지 안 준다.**
   앞뒤 도로명 같으면 "OO로 변 골목 횡단보도"(작음), 다르면 "OO로 횡단보도"(큼). 사거리에서 꺾으며 건너면 오판 가능 — 한계로 기록

## spots — 설계 결정 (사용자)
- 네비 아님. 중간 확인 화면도 안 만듦. 우리는 **출발 전 한 장: 이 개한테 걸리는 지점 + 한마디** — 실제 따라가기는 제공사 앱 딥링크(네이버/카카오/TMAP)로 넘김
- 방향전환·직진은 spot 아님. 횡단보도(큰길 여부)·계단·지하 통로(길이)·육교·엘리베이터·경사로·출발 통로·도착(앵커)
- 노트 = 시설 × 프로필: 큰길+반응성 → "다른 개 주의", 계단+노견/소형 → "안고 이동", 지하+대형 → "짧게 통과", 지하+겁많음 → "소음·울림"
- 랜드마크(nearPoiName/intersectionName)가 앵커: "버거킹 차병원사거리점 앞 논현로 횡단보도", "도착 — 학동역9번출구 근처"

## 콘솔에서 본 결과 (할매 · 강남역 → 역삼동물안과)
```
1 출발: 지하 통로 50m (이미 서 있는 곳)
2 테헤란로 횡단보도            큰길 — 목줄 짧게, 신호 기다리기 · 신호 한 번에 못 건너면 중앙 대기
3 국기원입구 앞 테헤란로 변 골목 횡단보도
4~5 테헤란로 변 골목 횡단보도
6 논현로 변 골목 횡단보도
7 도착                        간판·층수 확인, 진료 전 전화 권장
```
+ 폴리라인·번호 마커·따라가기(네이버/카카오/TMAP)

## 남은 것
- 큰길 판정은 도로명 접미(대로/로) + 앞뒤 동일 여부의 근사. 차로 수·횡단 길이는 TMAP에 없음
- OSM 타일은 개발용. 앱은 네이티브 SDK
