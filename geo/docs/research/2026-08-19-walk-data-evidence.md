# 조사: 산책에서 얻을 수 있는 데이터 — 논문 근거 (2026-08-19)

**질문**: 산책 1회에서 실제로 무슨 데이터를 얻을 수 있고, 각각 어느 정도 믿을 만한가. 폰만으로 되는 것과 목걸이 센서가 필요한 것을 가른다.

## 요약 — 세 층

| 층 | 얻는 것 | 근거 | 폰만으로 |
|---|---|---|---|
| **A. 직접 측정** | 시간 · 거리 · 속도 · 정지구간 · 궤적 · 시각 | GPS 검증 연구 | ✅ |
| **B. 파생 (경로 결합)** | 큰길/골목 비율 · 횡단보도 수 · 계단/지하 · 구역·재방문 | TMAP 실측 (research/tmap-live) | ✅ |
| **C. 개 행동 상태** | 걷기/속보/구보/정지, 냄새 맡기 | 목걸이 가속도계 검증 연구 | ❌ 목걸이 필요 |

## A. GPS로 직접 얻는 것 — 어느 정도 정확한가

**스마트폰 GPS 앱 vs 기준 거리** (Journal of MTM, 2017)
- 설계: **참가자 1명**, 3.58km 포장 트레일, 걷기 20회·달리기 20회
- 거리 오차(MAPE): **달리기 3.28%, 걷기 4.43%** (약간 과대추정)
- 에너지 소비 오차: 달리기 6.29%, **걷기 35.52%** ← 칼로리는 못 믿는다는 증거
- 한계: **n=1**, 평지·야외·개활지. 도심 협곡·나무 아래는 더 나쁨

**다른 검증** (PubMed 26505223): 스포츠 전용 GPS 대비 스마트폰 앱이 평균속도 −2%, 최대속도 −1.7%, 거리 −1.9% 수준 과소추정

→ **거리·속도는 ±2~5% 수준으로 쓸 만함.** 단 개활지 기준이고, 정지 중 GPS 지터가 거리로 누적되는 문제는 별도 필터 필요(속도 임계 이하 구간 거리 0 처리).

→ **칼로리는 걷기에서 35% 오차.** "63.7 kcal" 같은 표기는 근거 없음. 범위나 상대값으로만.

## B. 경로와 결합해 얻는 것

TMAP 보행자 경로 실측(research/2026-08-19-tmap-live.md)에서 구간마다:
- 도로명 → **큰길(대로/로) 비율** = 소음·차·밝기의 대리 지표
- turnType → 횡단보도 수(큰길 횡단 구분), 계단·경사로·엘리베이터
- facilityType 구간 → 지하 통로 길이

강남 5경로 실측: 계단 0 · 지하는 출발 역 통로뿐 · **횡단보도는 매번 있음(경로당 5~7)**. → 계단·지하는 희소, 큰길·횡단이 실질 축.

## C. 개 행동 — 목걸이 가속도계가 있어야 함

**8개 행동 상태 외부 검증** (PLOS One 2017, PetDialog+ 삼축 가속도계)
- 대상: **개 51마리, 36품종, 10~42kg, 6개월~13세**, 초 단위 분류
- 정확도(민감도/특이도): walk 0.91/0.91 · trot 0.91/0.78 · canter 0.96/0.92 · sleep 0.95/0.66 · static 0.86/0.97 · eat 0.92/0.73 · drink 0.89/0.87 · headshake 0.98/0.95
- 진단 유효도 >95%(보행류·먹기·마시기·머리흔들기), >90%(수면·정지)
- **한계: 냄새 맡기(sniffing)는 이 8개에 없음.** 콜리 3마리의 페이싱이 트롯으로 오분류

**활동량 표준화** (Royal Society Open Science 2024)
- 컷포인트 대신 **MXACC**(가장 활동적인 X분이 누적되는 가속도 임계) 제안 — M2ACC/M30ACC/M60ACC
- 활동/비활동 임계: 비글 콜로니 **0.154 g**, 반려견 **0.159 g**
- 행동별 평균: **누움 0.02 g · 걷기 0.26 g · 속보 0.59 g**
- 에폭 0.3초(≈3.33Hz, 개 보폭 주파수 범위), 샘플링 200Hz 사용하되 **실용 최소 25Hz 권장**
- 한계: **n=6 + 16마리**, 품종·체격 효과를 다루기엔 표본 부족

**기기 위치·리드 영향** (AJVR 2025, FitBark 2, 중대형견 10마리): 목줄 부착 여부·목걸이 위치가 활동량 출력에 유의한 차이 없음 → 목걸이 기기는 실사용 조건에서 견고

## 우리 설계에 대한 함의
1. `walk_advice`의 절대 cap("권장 ≤15분")은 근거 약함 → **개인 baseline 대비**로 전환, baseline 없으면 "초기 추정" 표기
2. `dog_time_factor`(1.2~2.0)도 prior. 2~4주 데이터 쌓이면 그 개 실제 속도로 교체
3. 정지 구간은 **케어 기록**으로만 (횡단보도 위치를 알므로 "신호 대기"와 "그 외 정지" 구분은 가능). 행동 이름 붙이지 않음
4. 세션 시작은 **사용자 명시적 시작**. 자동 감지로 혼자 걷기가 섞이면 baseline 오염
5. 웨어러블(FitBark류) 연동은 C층을 여는 유일한 길 — 계약만 열어두고 지금은 안 함
