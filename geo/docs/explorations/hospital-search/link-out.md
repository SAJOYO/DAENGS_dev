# 리뷰는 링크아웃 — 눈앞까지는 되고, 읽는 건 안 됨

- 카드 탭 → 우리 상세(기본정보·영업중·거리) → 하단 시트에 제공사 상세 페이지를 **인앱 브라우저(Chrome Custom Tab / WebView)** 로 렌더
- 렌더는 사용자 기기가 함. 우리 서버는 아무것도 안 읽음 → 크롤링 아님
- 네이버 모바일 플레이스 URL은 리뷰 탭까지 바로 감. 단 URL 패턴은 예고 없이 바뀔 수 있어 응답의 `place_url` 값을 그대로 쓴다
- 웹은 iframe 임베드 막혀 있을 가능성 → 새 탭 감수
- **WebView 안 내용을 JS로 읽어 에이전트에 넘기는 것은 다시 크롤링. 안 함**
