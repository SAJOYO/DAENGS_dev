# 영역 간 직접 import 판단표

기준 `0b53cb0e + #533`. Python 소스에서 서로 다른 소유 영역으로 연결되는 직접 import를 기록한다. 측정 내부의 과거 계산/응답 결합 C1은 제거됐다. [부채별 실제 수정 범위](README.md)를 함께 읽는다.

`retain-interface`는 현재의 기능 소비/계층 관계를 보존한다는 뜻이다. 해당 모듈의 모든 함수나 비공개 구현을 영구적인 공개 API로 승인하지 않는다. `change`도 기능 제거가 아니라 명시한 경계 변경이다.
