# 행동 핀의 장면·주변 정보 연결

DEV #371 · APP #233. 저장 계약은 [행동 핀 v2](action-pin-v2-storage.md),
기존 수집 구조는 [기록별 주변 정보](entry-contexts.md)를 따른다.

## 위치와 장면 계약

`walk-storyboard-candidates-v5`의 행동 장면은 `entry`와 별도 `pin`을 가진다.
pin에는 버전, resolution_id, 행동 시각(target_at), 확정 상태, 좌표, 위치 산출 방법,
불확실성 값과 근거가 들어간다. `estimated`와 `last_known`은 원본 관측으로 변환하지 않는다.
원래 content.location, 행동 시각과 기록 ID는 보존한다. 핀은 관측 경로 커버리지에 기여하지 않는다.

확정 좌표는 해당 행동의 주변 시설 조회에 쓴다. 추정/마지막 확인 위치라는 한정 문구가
시설 사실에도 붙고, 제목 생성에도 방문·현재 위치로 단정하지 않도록 전달한다.
`unlocated` 행동은 위치 없이 장면에 남으며 공간 조회를 보내지 않는다.
`provisional`은 기록 동기화와 확정 이후 분석하도록 409를 반환한다.

한 장면 생성의 Place 조회는 기존 경로 최대 8개 + 행동 핀 최대 8개, 동시 4개,
반경 250m, 요청별 3초다. 기존 전체 조회 기한 10초는 유지한다. 기한 초과 시 시설 근거는
unavailable로 표시하지만 행동 장면을 버리지 않는다. 8개를 넘는 행동도 장면에는 모두 남고,
시간순 앞의 위치 있는 행동 8개만 이 생성의 주변 정보 조회 대상이다.

## 수집 대기열

v2 저장 트랜잭션은 terminal pin 또는 핀이 없는 메모에 `walk-entry-context-v2` 작업을 예약한다.
미확정 핀은 예약하지 않고, 확정으로 부모 기록 버전이 증가할 때 예약한다.
기존 v1 작업과 정책 키를 분리하며, worker는 v2 읽기가 켜졌을 때 v2 작업도 처리한다.
외부 호출은 DB 세션 밖에서 하고 기존 버전·삭제·lease fencing을 그대로 적용한다.

결과 봉투는 원본 location과 pin/pin_revision을 함께 보존한다. 핀이 없는 메모는 원본 좌표를
쓰지만, 명시적인 unlocated 핀에는 원본 좌표를 대신 쓰지 않는다.
`GET /app/v2/walks/{walk_id}/entries/{entry_id}/contexts`가 현재 버전 결과를 조회한다.
이 대기열과 장면 생성 시의 bounded 조회는 서로 독립적이며 이번 단위는 공유 캐시를 만들지 않는다.

## 호환성과 적용

entry-capabilities에 `storyboard_formats`와 `entry_context_versions`를 추가했다.
APP은 활성 v2 기록이 있으면 v5 지원을 확인하고 v5만 요청한다. 미지원 서버에 낮은 버전으로
재전송하지 않는다. 기존 기록의 v4/v3/v2 협상과 v1 소비자 보호는 유지한다.
핀 버전/좌표가 바뀌면 서버 input fingerprint와 앱 분석 stamp가 바뀌므로 이전 결과를 확정할 수 없다.

추가 SQL/Room migration은 없다. 기존 기록·핀·주변 정보 테이블과 JSON 봉투를 재사용한다.
이미 배포된 DB에 해당 선행 테이블이 없으면 기존 마이그레이션을 먼저 적용해야 한다.
서버·worker 반영 → 지원 앱 연동/실기기 검증 → 최소 지원 버전 정책 확인 → 신규 v2 쓰기 활성화
순서다. 이번 PR은 배포, SQL 실행, 설치 및 플래그 활성화를 수행하지 않는다.

## 검증

서버 장면/제목/원본 근거/기록 v2/주변 정보 관련 7개 파일에서 102개 통과.
상한 검증을 추가한 뒤 신규 2개 파일과 DB 파일을 선택해 12개 통과, 로컬 격리 DB가 없어
DB 5개는 skip했다. PostgreSQL 17의 `walk entry context DB` CI에서 실제 대기열의
중복 예약, v1/v2 정책 분리, 읽기 플래그, rollback/lease/삭제를 검증한다.
외부 Place와 제목 생성은 테스트 대역을 사용했다. 실제 서비스·GPS 실기기 검증은 후속이다.
