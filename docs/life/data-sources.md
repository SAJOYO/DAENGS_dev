## 12. 수집 예절 / 법적 주의

- robots.txt 준수, 요청 간격 1~2초(현재 크롤러 기본 1.5s), UA 에 연락처 명시.
  **판정은 표준(RFC 9309 §2.2.2)의 longest-match 다** — `Disallow: /` 아래에 `Allow: /특정경로` 를
  적는 사이트(정부24)가 있어서, 먼저 적힌 규칙이 이기는 `urllib.robotparser` 로는 열려 있는 경로를
  스스로 막는다. `crawler/core/fetch.py` 의 `Robots` 가 이것을 구현한다 (2026-08-27).
  같은 형태를 **에어서울**에서 또 만났다 (§5)
- **robots 허용 ≠ 수집 가능** (2026-08-29, `#57`). **정찰을 robots 만으로 하면 안 된다.**
  항공사 5곳이 robots 로는 열려 있었는데 실제로 페이지를 받아 보니 **셋이 막혀 있었다**:
  진에어·에어서울은 `403` + `Just a moment...`(Cloudflare 챌린지), 에어부산은 **TLS 핸드셰이크 거부**다.

  이유는 **`robots.txt` 가 정적 파일**이라는 것이다 — CDN 이 챌린지 없이 그냥 내주고, 챌린지는
  본문 페이지에서만 걸린다. 그래서 robots 만 보면 "열려 있다"가 나온다. **정찰의 마지막 한 걸음은
  반드시 실제 문서 URL 을 한 번 받아 보는 것이다.**

  두 가지가 더 붙는다:
  - **챌린지는 빈도로 켜진다.** 에어서울은 첫 요청이 `200` 이었다가 몇 요청 뒤 `403` 으로 바뀌었다.
    한 번 성공했다고 열린 것이 아니다
  - **TLS 거부는 UA 문제가 아니다.** 에어부산은 UA 를 빼도 핸드셰이크에서 끊긴다. 지문(JA3)을
    바꾸는 것은 UA 를 바꾸는 것보다 명백한 우회라 하지 않는다
- **`Content-Signal` 을 같이 읽는다** (2026-08-28). 진에어 robots 는 `Allow: /` 를 주면서
  `Content-Signal: search=yes,ai-train=no,use=reference` 를 적어 두고 GPTBot·ClaudeBot 등은 막는다.
  우리 용도는 **출처를 표기한 참조**라 `use=reference` 에 해당하고 학습은 하지 않는다.
  **allow/disallow 만 보면 놓치는 층이다** (RAG-034 ⑤)
- **`User-agent:` 줄이 없는 allow-list** (DB손보·한화손보)는 표준상 무시되지만 **사이트의 의도는 제한**이다.
  공공기관이 아닌 곳은 의도 쪽으로 보수적으로 읽는다. **DB손보는 그 판단으로 뺐다** (2026-08-30, `#58` —
  우리 `Robots` 파서로는 통과하는 경로였다. 통과한다는 것과 받아도 된다는 것은 다르다. RAG-048 ①)
- 공공저작물은 대부분 **공공누리 제1유형(출처표시)** — 페이지별 유형을 `.meta.json` 에 기록
- 약관·항공사 안내는 사실정보 위주라 내부 RAG 활용은 무리 없으나, **서비스 표출 시 출처 표기 필수** (KPI 와도 일치)
- **robots 는 지자체마다 제각각이다** — 새올(`eminwon`) 고시공고를 파서 하나로 여러 지자체에서
  받으려다 확인한 것이다 (2026-08-28, `#42`). 같은 계열 화면이어도 판정이 갈린다:

  | 사이트 | robots | 판정 |
  |---|---|---|
  | 강화군 `www.ganghwa.go.kr` · 고성군 `eminwon.gwgs.go.kr` | 없음 (404) | ✅ 표준상 전부 허용 |
  | 군산시 `www.gunsan.go.kr` | `User-agent: *` → `Allow:/` (GPTBot·Amazonbot·Sogou만 차단) | ✅ 우리는 해당 없음 |
  | 동두천시 `www.ddc.go.kr` | Allow 목록 + `Disallow: /*view*` `/*selectGosiList.do` | ⚠️ 안내 페이지만. **고시 원문은 막힘** |
  | 세종시 `www.sejong.go.kr` · 영등포구 `www.ydp.go.kr` | `Disallow: /` | ❌ |
  | 정부24 `www.gov.kr` `/portal/locgovNews` | `Disallow: /` + Allow 목록에 없음 | ❌ (`/mw/AA020InfoCappView.do` 는 열려 있다 — §2) |

- **같은 기관인데 한 사이트만 robots 가 없으면 그것부터 의심한다.** `home.kahis.go.kr`(국가동물방역
  통합시스템)은 robots.txt 가 없어 표준상 열려 있는데, **같은 검역본부의 `qia.go.kr`·`animal.go.kr`
  은 전면 차단**이다. 표준만 보고 긁으면 기관의 의도를 우회하는 모양이 되므로, 수집 문의에 이
  사이트를 함께 넣었다 (`#42`). 위의 "공공기관이 아닌 곳은 의도 쪽으로" 규칙의 확장이다
- 원본은 git 미추적, `.meta.json` 필수, meta 없으면 인덱싱 금지 — [RAG-008](decisions-rag.md)
