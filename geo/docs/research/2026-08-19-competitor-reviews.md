## 불만을 유형으로 묶으면

### A. "기록이 안 남는다" — GPS 산책 앱 공통 1위
피리부는강아지 126건 중 45+44+25. 경로 안 그려짐, 운동장 한 바퀴가 반 바퀴, 4km가 1.8km, 시간만 흐르고 경로는 일직선, 종료 버튼 누르면 흰 화면, 1시간 반 걷고 기록 0. 펫피도 "산책 실행 시 하단 무한 로딩", 인투펫 "산책 오래하면 끊어짐".
→ **산책 앱의 본질은 GPS 신뢰성이고, 거기서 깨지면 나머지(기부·포인트·커뮤니티)는 아무 의미 없다.** 리뷰가 직접 그렇게 씀: "산책기록이라는 제일 중요한 본질을…"

### B. "업데이트하니 내 기록이 사라졌다" — 종합형의 죄
인투펫: 1년 체중기록, 200개 게시물, 병원비 메모, 사진 — 강제 업데이트마다 유실. "수첩에 옮기고 수기로 적는 게 백배 낫다".
→ **기록은 사용자 소유다.** 서버 마이그레이션 실패 = 신뢰 영구 상실.

### C. "기능이 너무 많아서 본래 기능이 망가졌다"
인투펫 1점: "불필요한 기능이 너무 많이 추가되면서 로딩 길어짐… 식단수첩도 필요 없음… 본래 기능에 충실하셨으면". 펫피 3점: "쇼핑 카테고리 세분화 안 돼 찾는 데 오래 걸림".
→ 종합형 포털로 가면 욕먹는다. **하나를 확실히**.

### D. "데이터가 없다 / 못 믿겠다" — 병원 앱
마이펫플러스 "등록된 병원이 적다", "후기 정렬 못 하게 해서 고평점만 보이게 조작 같다", "광고판·장사꾼". 펫트라슈 "주변 병원 0개", "현재 위치 옆동네".
→ **병원 앱의 신뢰는 커버리지 + 투명성.** 제휴 병원만 보여주는 모델은 "광고판"으로 읽힌다. 리뷰 정렬 못 하게 하면 조작으로 읽힌다.

### E. "가입부터 못 한다"
펫트라슈 1점 전부 가입/인증. 인투펫 19건이 로그인·인증·실행 불가. "네이버 검색해서 들어가면 로그인 되는데 앱을 왜 깔라는지".
→ 기능 이전에 **진입 장벽**. 가입 없이 검색은 되게.

### F. "보상이 사용자를 망친다"
한경 리뷰: 산책 중 포인트가 보여서 노견 적정량 초과. 펫피 저점: 교환 상품 축소 → "포인트 모을 이유 없음". 피리: 오류로 사료알 못 받으면 1점.
→ **보상이 본체가 되면 보상 정책 변경 = 이탈.** 그리고 산책 중 보상 노출은 개한테 해롭다.

### G. 운영: 고객센터·알림·광고
"기종만 묻고 해결책 없음", "알림 거부해도 매번 팝업", "산책일지 아래 광고 생김".

## 우리 설계에 연결 — 이미 맞는 것 / 조심할 것

| 리뷰가 말하는 것 | 우리 설계 | 판정 |
|---|---|---|
| A. GPS 신뢰성이 전부 | 산책 세션 엔진(니 영역)의 1순위가 **위치 배치 유실 없는 수집·임시저장** 이어야 함. 스토리보드·이미지·보상보다 앞 | ⚠ 문서엔 있는데 "배터리 vs 반응성" 정도. **1분 단위 임시저장, 오프라인 큐**를 1급 요구로 올려야 |
| B. 기록은 사용자 소유 | 프로필은 외부 계약, 산책 기록 저장 정책 미결 | ⚠ "업데이트해도 안 날아감"을 명시적 비기능 요구로 |
| C. 기능 과다 | 오늘 분리한 것: hospital / pharmacy / journey / walk 각각 얇게. companion으로 개 요소 끄기 | ✅ 방향 맞음. **세션 엔진에 식단·케어 붙이지 말 것** |
| D. 커버리지 + 투명성 | POI 원천 = 공공데이터 전수(제휴 아님). 리뷰는 링크아웃(조작 의심 원천 차단). 부스트는 밴드 내에서만, 근거 표시 | ✅ **정렬 이유를 보여주는 것**(`evidence`, `why`)이 "광고판" 인상의 정반대. 유지 |
| D. 위치 틀림/0개 | 직선 반경 + 결과 0이면 `reply`가 반경 넓히기 제안 | ✅ + 위치 권한 실패 시 수동 핀 |
| E. 가입 장벽 | 검색·journey 전부 무상태, `dog_id` 선택 | ✅ **로그인 없이 검색 가능**을 원칙으로 박기 |
| F. 산책 중 보상 노출 | "이동 중 알림 최소, 출발 전·종료 후에 무게" (overview) | ✅ 리뷰가 그대로 증명. **포인트는 종료 후** |
| F. 보상 변경 = 이탈 | 산책 메타는 테마 해금/구역 탐험 — 교환 상품 없음 | ✅ 교환형 포인트 안 하는 게 맞음 |
| G. 알림 팝업 반복 | — | 앱 팀 메모 |

## 시장에서 비어 있는 것 (리뷰가 안 쓰는 말)
- 어느 앱도 **"이 길이 내 개한테 어떤가"**를 안 함. 전부 거리·시간·칼로리·포인트. 우리 `advice`/`spots`/큰길 비율은 경쟁 없음
- 어느 앱도 **병원 가는 길**을 안 함. 병원 앱은 "어디"만, 산책 앱은 "기록"만. `journey` 공용이 정확히 그 사이
- 멍책이 **자기 사진 카드**를 막 시작함 — 스토리보드 "자기 사진 본체" 결론과 같은 방향. 로드뷰 없이도 되는 증거
