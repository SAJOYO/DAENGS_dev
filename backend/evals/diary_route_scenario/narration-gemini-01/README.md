# 보호자 시점 · 같은 재료 비교

2026-09-14. 구현·판단·검사·재현 명령은 [문서](../../../../docs/walk/diary-narration.md)에 있다.

- preview.html: 이전 공간+행동 문장과 새 결과를 나란히 표시한다.
- input.json: 같은 재료 확인용 입력, 실제 프롬프트, 정책과 소스 지문.
- case-N-space.json.gz: 공간의 실제 공급 trace·응답·내부 작업 결과. 원본 JSON 바이트를 압축했다.
- case-2-action.json: 행동 핀 하나의 실제 입력·응답.
- result.json: 실제 카드 조립기의 결과.

Gemini 7회(공간 6·행동 1), 공공 API·제목·자동 재시도 0회.
GPS와 행동 핀은 합성이고 공공자료는 저장된 실제 응답이다.
기존 비교 문장을 다시 생성하지 않았다. 새 문장도 수정하지 않았다.

공간 작업의 내부 evidence에는 원자료 추적 정보가 들어가 파일이 크다.
모델에 이 작업 객체를 보내지 않는다. 실제 공간 공급 내용은 job.tool_trace의 초기 입력과
선택한 상세 반환이며, 모델에 보낸 행동 내용은 input이다.
압축본도 재호출 방지 대상이다. --render-only는 모델을 호출하지 않는다.
