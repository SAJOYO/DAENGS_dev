# 이름·인허가 태깅 — 공짜 1층

한국 동물병원은 **응급 여부는 이름에 넣고 과목은 안 넣는다.**
"OO24시동물의료센터", "OO동물외과", "OO2차의료센터" — 이름만으로 24시/응급/외과/센터급이 갈림.

- 적재 시 `사업장명` 정규식 → `place.tags[]`: `24h`, `emergency`, `surgery`, `center`, `secondary`, `cat_only`(제외 대상) …
- 인허가 데이터의 **`면적`·`종사자수`** = "규모" 축의 유일한 객관 지표. 142㎡/1인 vs 800㎡/15인
- 공공데이터라 저장 자유. 약관 무관

**과목은 어휘에서 뺐다 (#64)**: 이름에 드물기도 하지만(28,284곳 중 109곳), 근본적으로
한국 수의 진료에 과목 제도가 없어서 그 단어는 자격이 아니라 상호다. 채워줄 후보였던
`community-search.md`·`kakao-category.md` 도 같이 기각됐다. 남는 어휘는 영업 형태
(24h·night·emergency)와 규모/유형(center·secondary), 종 배제(cat_only)다
**역할**: 이름 태그는 기본적으로 선호 부스트 + 표시다. 신뢰도가 낮아 결과를 제거하지 않으며,
사용자가 `require`로 명시한 태그만 필터가 된다. 규모는 표시만 하고 정렬에는 쓰지 않는다.
