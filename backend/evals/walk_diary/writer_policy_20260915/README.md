운영 어휘 연결 추가 (2026-09-15)
- production_vocabulary.json: 합성 지점 비교 두 건을 실제 write_brief_task → 운영 프롬프트 → generate_relation_part로 호출한 결과. 두 건 모두 응답·인용·발행 결과 검증을 통과했다. 호출 간격 10초, 재시도 없음.
- 신규 v3 작성과 숏메모리의 지점 비교에 shared_background / contrasting_background / closer_at_this_scene / farther_at_this_scene / comparable_distance를 적용했다. 이전 v2 원시 result 입력은 과거 발행본 검증에만 남는다.
- 구간 거리열을 만드는 운영 어댑터는 아직 연결하지 않았다. 아래의 drawing_closer 등 구간 실험과 이번 지점 비교의 운영 연결은 범위가 다르다.
- 실제 출력에는 ‘매헌로를 따라’, ‘상점들을 지나쳤다’처럼 두 지점 근거보다 강한 이동 표현이 남았다. 어휘가 전달된 것과 의미 품질을 구분한다. 프롬프트는 이번 수정에서 변경하지 않았다.
- 재현: backend에서 uv run python tools/run_writer_vocabulary_smoke.py --env <환경 파일> --output <결과 JSON>.

아래는 기존 구간 실험의 기록이다.

구현
- relation_flow_contracts.py: 내부 거리 관측열·관계 원장·선택 결과 계약.
- relation_flow_analysis.py: 접근·멀어짐·접근 후 멀어짐·거리 유지·곁을 따라감·지나침 계산과 기존 회전·되짚기·복귀 연결.
- relation_injection.py: 장면에 해당하는 관계 선택. 동일 대상의 구간 관계가 있을 때만 중복된 두 점 거리 비교를 대체한다.
- relation_delivery.py: 선택된 관계를 drawing_closer / drawing_closer_then_away / retracing / coming_back 등으로 전달한다. 원자료와 내부 판정은 별도로 남긴다.
- 모델에 중심 지정·필수 관계 서술·문학적 문체 지시를 넣지 않았다. 생성문을 사실로 쓰지 않고, 전달 경계를 지난 선택 자료만 숏메모리에 남긴다.

최종 실제 주입
1: 현재 공간 자료.
2: drawing_closer.
3: turning_back + carrying_on_straight + drawing_closer_then_away.
4: retracing + drawing_closer_then_away.
5: carrying_on_straight + coming_back + leaving_behind.

이번 공원 자료는 등록점이므로 passing_by / staying_alongside로 확대하지 않았다. 실제 경계·대상 축·유효 이동 자료를 받는 케이스는 코드 검사에서 확인했고, 이 공원 시나리오의 실제 모델 입력에는 사용하지 않았다. 20m 변화·30초 최대 관측 간격 등은 버전이 있는 초기 실험 정책이며 운영 실측 기준으로 확정한 값은 아니다.

실행
- 같은 합성 15분 왕복 동선, 고정 공원·상권·피복·도로 자료. 추가 공공 API 조회 없음.
- gemini-3.1-flash-lite, temperature=0. 호출 완료 후 최소 10초, 자동 재시도·별도 검수 없음.
- 최초 전체 실행 9회 후, 회전의 대표 시각과 분석 범위 끝을 혼동한 선택 문제를 수정하고 최종 전체 실행 9회를 수행했다. 총 18회 시도. 첫 실행은 로컬 결과 ZIP의 first_attempt에 보존하며, 이 저장소에는 최종 실행을 기록한다.
- 최종 실행 112.469초. 공간 5회·행동 3회 모두 응답 및 인용 범위 통과. 제목 1회는 503으로 실패했다.
- 새 모듈 경계 검사 13개 통과(0.48초), ruff 검사 통과. 전체 저장소 검사나 운영 배포 검증은 하지 않았다.

출력 판단
- 입력이 단순 nearer/farther에서 실제 구간 관계들로 바뀐 것은 확인했다.
- 하지만 최종 5장면은 상업 시설 소개와 공원의 가까움·멀어짐을 여전히 반복한다. 공간과 행동에 걸치는 이동 관계의 배치는 후속 조정 대상이다. 특히 회전이 공간 문장에 없다는 것 자체를 실패로 판정하지 않는다.
- 첫 문장에는 제공하지 않은 ‘차분한 분위기’가 추가됐다. 행동 3건 모두 ‘잠시 멈춰 서서’를 추가했지만 현재 행동 입력에는 정지 근거가 없다.
- 마지막 입력의 coming_back도 실제 문장에서는 빠지고 공원에서 멀어지는 설명을 골랐다. 인용 ID 통과를 의미 정확성으로 해석하지 않는다.
- ‘공원 1’은 합성 응답의 시험용 이름이다.
- 따라서 모듈 분리와 주입 연결은 확인했으나, 원하는 서술 다양성이 확보됐다고 보지는 않는다. 문학적 어휘로 관계 이름을 바꾸면 곧바로 좋은 일기가 된다는 결론도 낼 수 없다.

범위
새 모듈은 dev 작업 워크트리에 구현했고, 실제 호출은 실험 준비 어댑터를 통해 연결했다. 운영 일기 발행·DB·APP·배포는 변경하지 않았다. 이전 결과와 비교할 때 원자료는 같지만 새 계산 관계와 선택 메모가 달라지며, 다시 준비한 인용 ID·일부 목록 순서도 달라질 수 있다.
