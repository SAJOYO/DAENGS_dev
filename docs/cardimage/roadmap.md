## 배경 — 2026-09-15 사용자 방향

- Nano Banana 2 와 FLUX.2-klein-4B **둘 다 유지.** FLUX.2-klein-4B 는 자체 호스팅이고 크레딧 동안은 실험 여지가 크다.
- 하루 1회 한도는 Nano Banana 2 의 **장당 과금** 때문이었다 — FLUX.2-klein-4B 경로에서는 한도를 더 풀 수 있다.
- **한 번에 4장 정도 뽑고 사용자가 골라 저장**한다. 글씨 깨짐·목줄 같은 한두 장의 결함을 고르는 과정이 흡수하고, 같은 틀이어도 사람마다 다른 카드가 된다.
- 월 스페셜만이 아니라 **과일·채소 카드**에도 약간의 자유도를 줘 개인화한다.
- seed: 실험은 고정, 운영은 장마다 다르게 두고 **쓴 값을 저장**한다(09-15 `PETL PPAUSE` 3건이 전부 같은 seed 였다).

FLUX.2-klein-4B 에 대해 지금까지 잰 것(`compare-2026-09-15-cardgen.md`): 닮음 3.17(정면 5 · 옆 각도 3 · 엎드린 옆모습 1~3),
목줄 2/6, 문구 깨짐 3/12, 장당 18초, 콜드 스타트 425~430초, 요청 뒤 유휴 약 10분. 장당 비용은 **09-17 E4 실측**으로
정정됐다 — 73장 스윕 실측 장당 ₩24.2, 12장을 몰면 산출 약 ₩72/장, 한 장만 만들면 약 ₩720/장
(`compare-2026-09-17-klein-e4-cost.md`).

## 2번 — FLUX.2-klein-4B 실험 카드 (자세히)

**목적:** 3·4번을 설계할 때 필요한 숫자를 크레딧이 무료인 동안 모은다. 제품 코드(앱 경로)는 바꾸지 않는다.

**공통 규칙**
- 돈이 나가는 실행 전에 조건·장수·예상 비용을 설명하고 승인받는다. 실패는 매 시도 원인을 확인/추정으로 갈라 적는다.
- 판정은 검수 점수만 믿지 않고 격자 이미지를 눈으로 본다. 제목의 강아지 이름은 **영문**(예: `MOMO`) — 검수가 한글 이름을 깨진 글자로 오판한다.
- 비교할 때 seed 는 고정한다.
- 결과는 `docs/cardimage/compare-*.md` · `worklog.md`, 산출물은 `cardimage/out/_cardgen/<실험>/`(미추적). 끝나면 위 체크리스트를 체크한다.

### E1. 글씨 유지

| 조건 | 내용 |
| --- | --- |
| ① 프롬프트 | 아래 패널 문구를 그대로 적는다(예: "keep the text `PETAL PAUSE` exactly"). 달마다 문구를 `catalog` 에 두는 방식 검토 |
| ② 해상도 | 1024×1632 → **1280×2048**(2.6MP, FLUX.2-klein-4B 상한 4MP, 서비스는 2048 까지 받음) — 생성 시간 1.5~2배 예상 |
| ③ ① + ② | |
| 대상 | 깨졌던 조건(4월 · seed 1) × 사진 3장 → 조건당 3장, 이어서 9월 확인 |
| 판정 | 문구 정확 여부(눈) · 닮음 · 목줄 · 장당 시간 |

**09-16 결과(잠정):** 문구 명시는 **더 깨졌다**, 1280×2048 은 깨지는 자리를 옮겼을 뿐이고 40% 느리다. 같은 틀·seed·크기면 사진이 달라도 같은 자리가 깨진다 →
조건을 바꾸지 말고 **달 틀마다 글씨가 안 깨지는 seed 를 미리 골라 둔다**. 상세 `compare-2026-09-16-klein-e1.md`.

### E3. 콜드 스타트 줄이기

지금 로드 425~430초(버킷 ~15GB, GCS FUSE). 후보:
- GCS FUSE 마운트 옵션(파일 캐시 · 병렬 다운로드) — 서비스 메모리 증가와 교환
- 가중치를 이미지에 굽기 — 09-15 새 이미지(~10GB) 첫 가져오기가 5분이었으니 오히려 느릴 수 있다(재야 안다)
- 시작 CPU boost

판정: `load_seconds` 와 인스턴스 기동~ready 전체 시간.

**09-16 결과(잠정):** 기준(기본 FUSE) 로드 374.9초 · 403.1초 · 340.7초. `enable-buffered-read=true` 는 **735.6초로 2배 느림**. in-memory 파일 캐시(`cache-dir=cr-volume:…`)는
컨테이너가 **마운트 단계에서 못 떠** 재지 못했다(문서에 완전한 예시가 없어 원인 미확정, 추측 재배포는 안 함). 가중치 굽기·CPU boost 는 이유만 적고 안 쟀다.
→ 설정은 기본 유지. 콜드 스타트는 3번 카드에서 "사용 시간대 최소 인스턴스" 같은 운영 쪽으로 푼다. 또 **배포만 해도 인스턴스가 떠서 로드한다**(배포 한 번 = L4 약 7분 + 유휴 10분).
⚠ 가중치를 다시 받게 되면 `fetch.py`(한 파일씩, `max_workers=1`) 경로는 **실제 잡으로 아직 안 돌려 봤다** — 09-15 성공은 잡 명령을 `hf download` 로 덮어쓴 실행이었다. 첫 실행은 로그를 지켜본다.

### 09-18 (#593) — 앱 경로도 두 종을 받는다 (D-085)

**앱 표가 종류 카드를 담게 됐다.** `ai_cards` 에 `card_key VARCHAR(20) NOT NULL` 이 생기고 `month` 가
nullable 이 됐다(`db/migrations/2026-09-18_ai_cards_card_key.sql`). `POST /app/ai-cards` 는 전환기라
