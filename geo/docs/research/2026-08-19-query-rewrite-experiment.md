# 실험: 프로필 기반 쿼리 재작성 검색 (2026-08-19)

페르소나 3마리, 주인 입장에서 병원 갈 상황 → 쿼리 재작성 → 검색 → **결과에서 뭘 얻는지**.
카카오맵·네이버 지도·네이버 검색은 이 환경에서 접근 불가라 웹 검색(구글 계열)으로 대체. 플랫폼은 다르지만 "병원이 스스로 노출하는 정보가 뭔지"는 보임.

## 케이스
- **콩이** (보더콜리 2세) — 산책 중 뒷다리 절뚝, 저녁 8시 → 관절/정형 + 지금 열린 데
- **두부** (퍼그 5세 과체중) — 여름 낮 산책 후 헐떡임, 밤 11시 악화 → 24시/응급, 가까운 데
- **할매** (말티즈 13세) — 눈 뿌옇고 부딪힘, 급하진 않음 → 안과, 낮, 걸어서

## 1차: 딱딱한 쿼리
`강남역 동물병원 정형외과` / `강남역 24시 동물병원 응급` / `강남역 동물안과`

| 케이스 | 결과 |
|---|---|
| 두부 (24시) | **잘 됨.** 이름에 "24시" 박힌 병원이 바로 잡힘 (24시우리들, 예은, VIP, 더케어…) |
| 콩이 (정형) | 애매. "정형" 이름 병원은 강서·수원 등 멀리. 강남 2차 센터(예은)는 정형 센터를 품고 있지만 **홈페이지 들어가야 보임** |
| 할매 (안과) | 안 됨. "안과" 이름 0. 전부 24시 센터로 튐. 조건 충돌(걸어서 vs 안과 특화는 멀리) |

검색 결과 자체가 주는 정보: 이름에 박힌 신호(24시·응급·센터·외과·2차), 주소·전화. **진료시간·과목·의료진·입원은 없음** → 홈페이지에만.

## 2차: 주인 말투 쿼리 (사용자 피드백: "LLM이 너무 정제했다")
`강아지 뒷다리 절뚝거려요 강남 동물병원 어디가 좋아요` / `퍼그 밤에 숨을 헐떡거리는데 강남 지금 갈 수 있는 동물병원` / `13살 말티즈 눈이 뿌옇고 자꾸 부딪혀요 강남 동물병원 추천`

| 케이스 | 걸린 것 |
|---|---|
| 할매 | N동물의료센터 **건강상담 FAQ**("눈이 하얗게 변했다면…" 녹내장/백내장), 포인트동물의료센터 **안과센터 페이지**, 분당밝은아이동물병원(안과 전문), 당신의동물의료센터 안과 |
| 콩이 | 뉴스1 "정형외과 동물병원 선택 기준", 핏펫 관절 블로그, 청담우리동물병원 |
| 두부 | 예은 (스니펫에 **세부 전공 목록**), 월드펫 + 노이즈(틱톡 밈, 앱스토어, 나무위키) |

**차이**: 증상 언어로 치면 병원이 그 증상 잡으려고 써둔 FAQ·칼럼·센터 소개가 걸리고, 거기서 "이 병원은 안과를 표방한다"가 드러남. 이름에 없어도.

## 같이 오는 문제
1. **위치가 풀림** — 강남 넣어도 분당·수원. 특화 병원은 드문드문이라 엔진이 지역을 느슨히 봄 → 병원명을 우리 DB(좌표)와 매칭해 거리는 우리가 재계산
2. **노이즈 절반** — 틱톡·앱스토어·위키 → DB 미매칭 버림이 자동 필터
3. **증상 문진성 콘텐츠** 딸려옴 → 관할 밖. 병원명 추출에만 씀

## 판단
- 응급/24시는 검색으로 끝나고, 과목은 **딱딱한 검색으론 안 끝나지만 증상 언어 + 커뮤니티 코퍼스면 상당 부분 잡힘**
- 네이버에선 이런 쿼리가 지식iN·카페·블로그로 감 → 도구는 **네이버 검색 API** (`community-search.md`)
- 홈페이지 온디맨드 추출은 후순위 (`homepage-enrich.md`)
