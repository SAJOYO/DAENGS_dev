# 반려견 프로필 계약 + 가상 페르소나

프로필 원천은 **타 담당**. 이 레포는 소비자다. 아래 인터페이스만 계약으로 잡고, 저쪽 저장 방식은 관여하지 않는다.

견주(사람) 쪽 제약은 여기 없다 → [owner-profile.md](owner-profile.md).

## 인터페이스 (수신 형태 가정)

```
필수 ─────────────────────────────
dog_id, name
breed              혼합이면 [{breed, ratio}]
birth_date         → age는 서버가 계산
sex, neutered
weight_kg
size_class         small / medium / large   (품종 미상 대비)
profile_version    변경 감지용. 바뀌면 파생값 재계산

선택 (있으면 판정 정밀도 상승) ─────
brachycephalic     bool  ← 없으면 breed로 유추
health_flags       []    예: joint, heart, obesity, senior, unvaccinated
activity_level     low / mid / high  (보호자 자기보고)
temperament        []    예: curious, timid, food_driven, reactive_to_dogs
walk_baseline      { avg_min, avg_km, usual_time }  ← 없으면 첫 2주 학습
```

`has_car`는 **개 속성이 아니다.** `DogProfile`에 남아 있지만 deprecated이며 `OwnerProfile.has_car`로 옮겼다.
`walk_baseline`은 계약에만 있고 아직 `contract.py`에 없다 (산책 세션 착수 시).

## 페르소나를 가르는 축: **지도 위에서 이 개한테 걸리는 것**

견종 인기순도, 크기 격자도 아니다. "병원까지 가는 길에서 뭐가 문제인가"로 갈랐다.
한 마리가 한 난점을 맡고, 8마리가 경로 판정의 분기를 전부 밟는다.

| # | 개 | 프로필 | **지도 위 난점** | 판정에 걸리는 것 |
|---|---|---|---|---|
| 1 | **콩이** | 보더콜리믹스 · 2세 · 18kg · medium · high · reactive_to_dogs | **다른 개 마주침.** 체력은 남는데 번화가·공원 앞에서 문제가 생긴다 | 골목 섞인 길 선호, 큰길 횡단 3회↑ 경고 |
| 2 | **두부** | 퍼그 · 5세 · 9kg · small · brachy · obesity | **여름 기온.** 28℃면 거리와 무관하게 나가면 안 된다 | 단두종 상한 20분, 기온 경고 |
| 3 | **할매** | 말티즈 · 13세 · 3.2kg · small · senior+joint · timid | **계단 = 통행 불가.** 신호 한 번에 횡단을 못 끝낸다 | 상한 15분, 계단 avoid, 중앙 대기 노트 |
| 4 | **바우** | 골든리트리버 · 4세 · 32kg · large | **통로와 탑승.** 걷는 건 제일 잘하는데 지하보도 울림, 대중교통 동반 거절, 택시 승차 거부로 **선택지가 도보뿐** | 지하 통로 스트레스, 대중교통 미노출 |
| 5 | **뽀글** | 포메라니안 · 2세 · 2.1kg · small · joint · high | **슬개골인데 어리고 활발하다.** 할매는 '못 가는' 거고 얘는 **'가겠다는 걸 말려야'** 한다 | 상한 15분(4kg 미만+관절), 계단 금지 |
| 6 | **초코** | 카발리에 · 9세 · 7.5kg · small · **heart** · timid | **경사·계단에서 호흡이 무너진다.** 평지 거리는 버틴다 | ⚠ **미배선** — 아래 참조 |
| 7 | **삼월** | 믹스 · 3개월 · 1.8kg · **unvaccinated** | **땅에 못 내려놓는다.** 다른 7마리는 '어느 길로'가 문제인데 얘만 **'걸어갈 수 있나'**가 문제 | ⚠ **미배선** — 아래 참조 |

카발리에를 고른 이유: 승모판 질환 호발종이면서 **단두종이 아니다.** 시츄로 하면 brachy와 섞여 심장 신호가 묻힌다.

## 이 페르소나들이 드러낸 구멍

페르소나를 늘리자마자 **선언만 되고 아무것도 안 하는 필드**가 드러났다. 지금은 기록만 하고 로직은 안 건드렸다.

| 구멍 | 현재 | 있어야 할 것 |
|---|---|---|
| `health_flags: heart` | **코드 참조 0건.** 초코가 건강한 개와 같은 45분 상한을 받는다 | 상한 하향 + 경사/계단 가중. `Facilities`에 경사 재료가 이미 있다(`slope`) |
| `health_flags: unvaccinated` | **코드 참조 0건.** 삼월에게 "48분은 과하다"고 답한다 — 사실은 **0분이 맞다** | 도보 자체를 불가로. `advice=avoid` + "이동장/안고 이동" 서술. 조용한 침묵이 제일 위험 |
| `health_flags: obesity` | **코드 참조 0건.** 두부의 avoid는 전부 brachy·기온에서 나온다 | 상한 하향 또는 계수 가산 |
| `has_car` | 프롬프트 힌트 문자열에만 등장 | `OwnerProfile`로 이동 완료. mode 기본값 배선은 아직 |
| 대중교통 노출 | **배선 완료**: 개 크기 + `OwnerProfile.transit_ok` | 실제 외부 프로필 원천 연결 |

## 페르소나에서 도출된 규칙

1. **하루 목표는 프로필 함수다.** 입력: 나이·체중·brachy·flags·기온 → 출력: 권장 시간/거리 범위. 고정값 없음
2. **정지 판정 임계값은 개마다 다르다.** 콩이 3분 정지 = 뭔가 있음, 할매 3분 정지 = 그냥 쉼
3. **톤은 temperament에서, 경고 강도는 health_flags에서.** 분리해야 귀여운 말투가 위험 경고를 묻지 않는다
4. **사유는 실제로 해당하는 것만 말한다.** 계단 경고를 `노령·관절`로 뭉쳐 두면 2세인 뽀글에게 "노령"이라고 한다 — 2026-08-20 수정
5. **모름은 불가가 아니다.** 재료가 없으면 `None`을 내고 판정을 지어내지 않는다 (`OwnerProfile.can_carry`)
