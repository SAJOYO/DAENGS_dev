# 조건으로 장을 골라 겹치면 심어둔 행동 패턴이 회수되는가

2026-08-26 실험. 재현:

```bash
uv run python -m scripts.spikes.territory_paint.persona_year --cache osm.json --json personas.json
uv run python -m scripts.spikes.territory_paint.persona_experiment --personas personas.json --cache-sheets sheets.pkl
```

코드는 `app/features/territory/layers.py` · `scripts/spikes/territory_paint/persona_{year,experiment}.py`.
갈래는 [territory-paint](../explorations/walk/territory-paint.md).

## 무엇을 물었나

셀로판 모델의 주장은 하나다.

> 산책을 독립된 장으로 보존하고 태그로 다시 골라 겹치면, **전체 누적에서는 사라지는**
> 행동 맥락을 복구할 수 있다.

앞의 두 측정([면 근사](2026-08-26-region-cell-fidelity.md), [붓 감쇠](2026-08-26-brush-falloff.md))은
**기하**를 쟀다. 이번엔 파이프라인 전체 — 선택 · 재합성 · 판독 — 를 잰다.

## 정답을 심어서 만든다

실기기 데이터에는 정답이 없다. 누가 왜 그 길로 갔는지 아무도 모른다. 그래서 패턴을 **심은**
1년치를 만들었다. 5배 규칙 측정에 참값 궤적이 필요했던 것과 같은 구조다.

```
관측값(질의층이 보는 전부)   walk_id · started_at · route
정답지(평가기만 본다)        family · intended
```

파생 태그(계절·시간대·요일)도 원천에 안 넣는다 — `started_at` 에서 질의층이 뽑는다. 그래야
"태그를 파생할 수 있나" 까지 검증 대상에 들어온다. 시간대 경계도 생성기와 **독립**으로
정의했다(`layers.TIME_BANDS`).

### 페르소나 7명 — 난이도 순

실제 OSM 보행 도로망(대치·도곡동 + 양재천) 위, 사람마다 다른 집. 359회/년.

| | 심은 것 | 검증 |
|---|---|---|
| **A** null | 계절·시간대·경로 횟수를 **균형 고정** | 거짓 양성 통제 |
| **B** seasonal | 봄가을 공원 / 여름 하천 / 겨울 골목 | 단일 축 회수 |
| **C** time | 아침 골목 / 저녁 공원 | 다른 단일 축 |
| **D** drift | 분기마다 갈 곳이 하나씩 는다 | 활동권 확장 |
| **E** correlated | 여름은 80% 밤 · 밤은 하천 · 낮은 골목 | 얽힌 태그 자르기 |
| **F1/F2** mirror | **같은 집·같은 경로**, 계절 배정만 정반대 | 숨은 구조 회수 |

A 를 확률이 아니라 균형 고정으로 만든 이유: 확률로 뽑으면 표본 잡음만으로 계절 간 그림이
달라져, 시스템이 멀쩡한데도 "거짓 양성 없음" 기준이 깨진다.

### 정답 영역은 배타 영역이다

산책이 왕복이라 집 앞 구간은 모든 경로가 공유한다. 그건 현실이고, 그 구간은 애초에
아무것도 구별하지 못한다. 그래서 회수율은 **그 family 만 닿는 칸**에서 잰다.

```
exclusive(river) = cells(river) − ∪ cells(다른 family)
```

목적지도 거리가 아니라 **경로 분기**로 골랐다. 처음엔 목적지끼리 멀도록 골랐는데 가는 길이
같은 복도를 공유해 정답 영역이 겹쳤다(Jaccard 0.2~0.46). 경로 노드 겹침으로 고르고 집
선택에 상한 0.30 을 걸어 셀 Jaccard 0.03~0.22 가 됐다.

### ε 는 고르지 않고 A 에서 얻는다

"거의 같다" 를 눈으로 판정하지 않는다. 패턴을 심지 않은 A 의 조건 간 최대 거리가
**잡음의 크기**이고, 그것이 ε 다.

| A 의 조건 쌍 | 정규화 거리 |
|---|---:|
| spring vs autumn | 0.0341 ← 최대 |
| summer vs winter | 0.0333 |
| morning vs evening | 0.0247 |

**ε = 0.0341.** 나머지 기준은 전부 이 자로 잰다.

## 결과 — 6 기준 전부 통과

### 1. 단일 축 회수

| | 회수율 | 층간 거리 | n |
|---|---:|---:|---|
| B 여름−겨울 → river 배타 129칸 | **0.980** | 1.3232 (38.8ε) | 90/90 |
| C 아침−저녁 → alley 배타 202칸 | **0.959** | 1.8688 (54.8ε) | 180/180 |

양의 질량의 96~98% 가 심어둔 family 의 배타 영역에 들어갔다. 거리는 잡음의 39~55배다.

### 2. 얽힌 태그 자르기 (E)

이것은 **원인 분리가 아니다.** 서로 얽혀 있는 태그로도 사건 집합을 AND 로 다시 잘라낼 수
있다는 것까지가 증명 범위다.

| 층 | n | river 배타 질량 |
|---|---:|---:|
| summer | 90 | 0.763 |
| night | 180 | 0.940 |
| summer ∩ night | 72 | **0.940** |
| summer ∩ day | **18** | **0.000** |

여름과 밤은 marginal 로 비슷하다(거리 0.357). 그런데 `여름 ∩ 낮` 으로 좁히면 하천이
**정확히 0** 이 된다. 가장 얇은 슬라이스가 n=18 이라 그 숫자를 같이 적는다 — 생성기의
여름 밤 비중을 0.85 가 아니라 0.80 으로 낮춘 것이 이 분모를 두 자릿수로 만들기 위해서다.

### 3. Null 보존 (A)

위의 ε 표. 패턴을 안 심은 사람은 어떤 조건으로 잘라도 그림이 3% 안에서 같다.
**거짓 양성이 없다는 뜻이고, 1·2·4 의 숫자가 뜻을 갖는 이유다.**

### 4. 숨은 구조 회수 (F1/F2) — 이 실험의 결론

같은 집, 같은 두 경로, 연간 횟수도 같다. 계절 배정만 정반대다.

```
연간 누적 거리          0.0158  (0.5ε)   ← 잡음보다도 가깝다
F1 여름−겨울 양의 질량 중 river   0.968
F2 여름−겨울 양의 질량 중 river   0.000
두 차이 field 의 코사인        −0.999   ← 정반대
```

**전체 누적만 저장했다면 F1 과 F2 는 구별되지 않는다.** 두 지도의 거리가 잡음의 절반이다.
그런데 장을 남겼기 때문에 계절 조건에서 거의 완벽하게 반대로 갈린다.

이것이 "장으로 남기면 이런 게 된다" 가 아니라 **"안 남기면 이걸 잃는다"** 를 보이는 자리다.

### 5. 활동권 확장 (D)

| 분기 | support | 증가율 |
|---|---:|---:|
| Q1 | 205칸 | — |
| Q2 | 337칸 | +64% |
| Q3 | 528칸 | +57% |
| Q4 | 518칸 | −2% |

갈 곳이 셋뿐이라 Q3 에서 다 찬다. 앞 둘은 확장이고 마지막은 정체이며, −2% 는 지터 잡음이다.

바뀌어도 지문이 달라진다(`tests/territory/test_layers.py`).

## 평가기가 생성기 버그를 둘 잡았다

층을 갈라 커밋한 값이 여기서 나왔다 — 실패가 어느 층 문제인지 바로 보였다.

1. **D 를 "넓어진다"로 설계하고 "옮겨간다"로 구현했다.** 두 family 가 섞인 분기가 순수
   분기보다 넓어져 support 가 205→338→410→216 으로 오르내렸다. 누적 확장으로 고쳤다.
2. **그래도 Q4 가 Q3 보다 2% 작았다.** family 가 셋뿐이라 Q3 에서 다 차기 때문이고 남은
   차이는 지터다. 네 family 를 요구해 봤더니 이 동네엔 그런 집이 하나도 없어서, 기준을
   "확장 후 정체" 로 바꿨다 — **시스템이 멀쩡한데 설계와 다른 잣대로 실패시키지 않는다.**

## 이 실험이 말하는 것

> 산책을 독립된 장으로 보존하고 태그로 재선택해 합성하면, 전체 누적에서는 사라지는 행동
> 맥락을 복구할 수 있다.

이제 예쁜 데모가 아니라 숫자가 있는 주장이다.

## 말하지 않는 것

- **원인 분리가 아니다.** E 가 보인 것은 얽힌 태그로도 집합을 자를 수 있다는 것뿐이다.
  "여름이라서" 인지 "밤이라서" 인지는 이 실험이 답하지 않는다.
- **가상 데이터다.** 심은 패턴을 찾은 것이지 사람의 실제 행동이 이렇게 깔끔하다는 뜻이 아니다.
  회수율 0.98 은 시스템 상한이지 기대치가 아니다.
- **문턱을 정하지 않았다.** `min_peak` 는 0 으로 돌렸다 — 등급은 데이터가 생긴 뒤 정한다는
  결정을 selection 단계에서 어기지 않으려고.
- **저장 경계를 안 정했다.** 단순화 궤적 vs 산책별 셀 맵은 여전히 열려 있다
  ([territory-paint §A](../explorations/walk/territory-paint.md)). 다만 이 실험은 **장 단위
  보존이 값을 한다**는 근거를 하나 보탰다 — 기준 4 가 그것이다.
- **성능.** 2,514 장을 칠하는 데 6 분이다(1 장 153ms). 실서비스라면 finish 때 한 장씩
  칠하므로 문제가 아니지만, 실험은 캐시에 의존한다.
