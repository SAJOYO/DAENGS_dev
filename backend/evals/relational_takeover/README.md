# 합성 기록 기반 회귀 자료

출처: 사용자 업로드 `산책일기_전체실험.html`, 그룹 `app-gps-skeleton-08`.

- `synthetic_source.json.gz`: 독립 합성 GPS와 합성 공간 자료. TMAP·실측 산책·새 공공 API 호출 아님.
- `historical_calls.json.gz`: 당시에 저장된 실제 모델 입력과 원문. 이번에 재호출한 결과 아님.
- `recorded_v4.json.gz`: 당시 발행 영수증. 잘못된 문장도 고치지 않고 보존.
- `prepared_v5.json.gz`: 당시 프레임을 v5 `make_plan`으로 재계획한 입력. 자료 관측일을 만들어 채우지 않았으며 원래 이동 관측을 보존함. GPS 측정 커널 재실행 결과 아님.

테스트의 검수 결과는 작성한 프로토콜 더블이다. 의미 검수 거절이 본문에 채택되지 않는 경계를 검사하며, 배포 모델의 실제 탐지율·문장 품질을 측정하지 않는다.
