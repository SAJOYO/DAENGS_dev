# Judge v3 — 동일 관측 재평가

원본 Lite 8턴과 별도 Codex 검토는 수정하지 않았다. v3는 판정 기준과 정책을 축별로 분리하고 결과 설명 축에서 사용자 요청을 제외했다. 의도·범위 입력 16개는 기존과 같고 결과 설명 입력 8개는 query만 빠졌다. 모든 Judge 입력이 같다는 비교는 아니다.

대조 사례 22/22, 실제 관측 24개 축, 호출 46회 / 오류 0회.
기존 Codex 검토와 일치: v1 21/24 → v2 22/24 → v3 24/24.
같은 계열 모델과 개발 사례를 보고 보완한 결과다. 사람 라벨·독립 평가 정확도가 아니며, 문구의 진위를 남은 관측으로 판단할 수 없다면 uncertain으로 남겨야 한다.

## 판정 변경 근거

- **FJ-D01·1**: 시스템이 검색 결과를 제시한 후, 추가적인 사용자 의도를 파악하기 위해 중립적인 되묻기를 수행했습니다. 이는 사실 관계를 왜곡하거나 완료되지 않은 작업을 완료했다고 주장하는 내용이 아니므로 사실성에 부합합니다.
- **FJ-D02·1**: 시스템이 검색 결과를 제시한 후, 추가적인 사용자 의도를 확인하기 위해 중립적인 되묻기를 수행했습니다. 이는 사실 관계를 왜곡하거나 완료되지 않은 작업을 완료했다고 주장하는 것이 아니므로 사실성에 부합합니다.
- **FJ-D07·2**: 시스템이 검색 결과를 제시하지 않고 사용자에게 추가 정보를 요청하는 되묻기 문구를 출력했습니다. 이는 사실 관계를 왜곡하거나 완료되지 않은 작업을 완료했다고 주장하는 것이 아니므로 사실성에 부합합니다.
