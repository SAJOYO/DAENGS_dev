## 운영성 및 결정

- BM25·RRF·rerank는 새 패키지 없이 구현 가능하고 65청크 메모리 비용은 작다.
- 그러나 품질 기준(전체 Hit@4/MRR, 기존 top-4 정답 보존)을 통과한 방식이 없다.
- **채택하지 않음**: BM25, RRF, top-20/top-50 lexical rerank 모두 프로덕션 retriever에 반영하지 않았다.
- **top_k 증가·질의 확장·ID별 예외**도 수행하지 않았다.
- 최종 후보가 없으므로 동일 25건의 추가 FastAPI E2E는 실행하지 않았다. 기존 API 기준선은 closeout 보고서의 Gemma 결과를 유지한다.

## oq0032 annotation 권고

`oq0032`의 질문은 “기다려를 처음 몇 초 성공하면 보상하는가”지만 gold quote는 보상 기반 교육 일반론이며 초 단위를 제공하지 않는다. 동결 v1은 변경하지 않고 별도 annotation 이슈로 유지한다. 이 행을 랭킹 개선 성공/실패의 단독 근거로 과대해석하지 않는다.

## 판정

랭킹 개선 실험은 기존에 평가한 BM25·RRF·top-20/top-50 **lexical 계열에 한해 `NO_LEXICAL_RERANK_ADOPTION`**이다. cross-encoder reranker는 이번 실험 범위에 포함되지 않았으므로 전체 reranker 기각을 의미하지 않는다. 현재 API 전체 상태는 기존과 같이 **CONDITIONAL**이며, 검색 품질을 포함한 READY는 아니다.

재개 명령:

```powershell
uv run python scripts/compare_retrieval_reranking.py `
  --input data/eval/queries/training_api_eval_v1.jsonl `
  --out-dir data/scratch/retrieval_reranking_next
```
