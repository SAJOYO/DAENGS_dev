# 공간 서술 A/B — 실제 Gemini 9회

2026-09-14. `public-02`의 풀밭·길·숲 3장면에 같은 정규화 재료를 사용했다.
공공자료는 실제 저장 응답이고 GPS·행동·메모는 합성 시나리오다.

- [비교 화면](preview.html): 생성 원문 6개, 공급 재료·호출 내역은 접힌 개발자 영역.
- [조건](experiment.json): 기준 코드·모델·프롬프트·입력·원자료 지문.
- [호출량](summary.json): Gemini 9회, 내부 상세 조회 3회, 추가 공공 API 0회.
- `case-*.json`: 시도별 원문·실제 입력 trace·사용량. 자동 재시도 없음.
- [검토와 해석](../../../../docs/walk/diary-space-comparison.md).

새 방식은 세 장면 모두 공원만 조회했다. 양쪽 모두 동·피복·공원만 최종 인용했고,
공간 문장의 이동 표현과 근거 없는 관계 결합이 남았다. **실제 도구 연결은 확인했으나
서술 품질 향상은 확인하지 못했다.** 문장을 수정하거나 다시 생성하지 않았다.

이 자료는 공간 작성기만 비교한 결과이며 전체 일기 발행·행동·제목을 실행한 기록이 아니다.
1단계 서술 예시는 프롬프트에 추가하지 않았다. 새 방식은 도구 지침과 입력 공급 단계가
함께 달라져, 공급 방식만의 효과를 분리한 실험은 아니다.
