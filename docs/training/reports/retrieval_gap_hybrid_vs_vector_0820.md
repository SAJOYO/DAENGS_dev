# retrieval-gap 4건 — 벡터 단독 vs 하이브리드 비교

측정일 2026-08-20. `scripts/run_combined_retrieval_eval.py`를 Q12·Q13·Q14·Q15 각각에 대해
`--graph-off`(벡터 단독)와 기본 실행(하이브리드)으로 두 번씩 돌린 결과입니다. 판정은
하지 않았습니다 — coverage 재판정이나 "이게 낫다"는 결론은 이 문서에 없습니다.

**생성 응답에 대한 사실 고지**: 이 저장소의 `scripts/generate_answers.py`는 현재
`dry-run` 모드만 구현되어 있고 실 API 클라이언트가 배선되어 있지 않습니다
(`build_client()`가 dry-run 외에는 `GenerationError`를 던짐). 아래 "생성 응답"은 두
조건이 검색한 근거 청크 전문을 `generate_answers.py`의 `PROMPT_RULES`(자료 안의 내용만
사용, 없으면 "자료에 없다"고 답하고 추측 금지, 인용 번호 표시)를 그대로 적용해 Claude가
이 대화 세션에서 직접 작성한 실제 생성 결과입니다 — 사람이 나중에 채워 넣는 dry-run
플레이스홀더가 아니라, 스크립트로 API를 호출한 것도 아닙니다. 이 사실을 밝히는 이유는
"실제 생성"이 이 리포지토리에서 어떤 경로로 만들어졌는지 오해가 없도록 하기 위함입니다.
