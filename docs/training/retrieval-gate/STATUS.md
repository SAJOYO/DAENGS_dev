## 환경 메모

- 이 저장소에 `pytest`가 의존성으로 없다. `uv run --with pytest python -m pytest -q`로 돌린다.
- `data/eval/queries/*`가 gitignore다. 대조군 파일은 `git add -f`로 넣었다.
- **3번도 Docker 가 필요 없다.** 서빙 청크가 `data/scratch/chunks_structure_v1/`에 있고
  로컬 인코딩으로 0827 dense 기준선이 소수점까지 재현된다.
- **이 PC 는 RAM 이 빠듯하다 — 16GB 중 가용 4~5GB** (qemu VM 이 2GB대를 상시 점유).
  torch 는 `2.13.0+cpu` 로 **GPU 를 못 쓴다**. 그래서 리랭커 실행은
  ① E5 인코더를 `del` + `gc.collect()` 로 놓은 뒤 리랭커를 올리고
  ② `--max-length 512` · `--batch-size 4` 를 유지한다.
  이걸 어기면 **트레이스백 없이** 죽는다 (예외가 아니라 OOM kill 이라 로그에 아무것도
  안 남는다). 2026-08-28 에 두 번 그렇게 끊겼고, 매번 dense 기준선 출력 직후였다.
  더 빠듯하면 `--model BAAI/bge-reranker-base` (278M) 로 내린다.
