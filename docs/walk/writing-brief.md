# 관계 일기 작성 입력 — 2단계

기준: DEV #545 제목·#546 주소 헤더를 포함한 `131a44a2`.
현재는 순수 도메인 계약과 준비 함수까지 구현했다. 실제 준비 서비스·작성기·발행본은
기존 경로를 사용한다. 다음 단계에서 이 계약으로 연결하며, 기존 저장본을 소급 변경하지 않는다.

## 하나의 공간 의미를 공유한다

```text
SceneSnapshot + 검증된 SpatialComparisonSlots + ScenePosition
 → build_space_context → NarrativeSpaceContext
 → build_space_brief(context, accepted_delivery)
    ├─ space_work_reason: 작업 여부·이유
    ├─ brief_writer_view: 실제 전송용 데이터
    └─ advance_brief_delivery: 채택된 선택으로 기억 갱신
```

`narrative_space.py`가 도로명·피복·주변 공원·넓은 영역의 특징을 투영한다.
`brief_contracts.py`가 공간/사건 계약과 고정 관계 슬롯(background, proximity, area_context)을 정의한다.
원본 비교는 원본 스냅샷에서 재계산해 확인한다. 서술 관계는 `nr:` ID를 새로 받고,
원본 관계·원본 사실은 내부 `source_bindings`로 추적한다. 기존 비교 ID의 뜻을 덮어쓰지 않는다.

상권은 정규화된 업종 구성·분포와 조회 반경을 보존한다. 등록 수·상가 ID 목록·자료 해시·조회 시각
변화는 서술 관계와 서명에 들어가지 않는다. 자료 계열·기준월·분류 정책·반경이 비교 가능하고
양쪽에 같은 종류의 특징이 있을 때만 특징 차이를 만든다. 알 수 없는 항목은 유지/소멸로 바꾸지
않고 `omitted_sources`에 사유를 남긴다. 알려진 특징의 새로운 문자열 값은 임의로 버리지 않는다.

공원은 원본 식별자로 동일 대상을 확인한 양 끝 거리만 비교한다. 내부 배경 서명에도 대상 식별자를
포함해 이름과 거리가 같은 다른 공원을 합치지 않는다. 이 식별자는 작성 입력에서는 제외된다.
GPS 구간은 관측 시간·거리·공백을 별도 계약으로 유지하며 공간 특징의 범위는 양 끝 기록점이다.

계획·전달 기억은 같은 `NarrativeSpaceContext.signature`를 사용한다. 최초 소개가 실패하면 다음
동일 배경에서 복구 작업을 열 수 있다. 일부 현재 근거를 선택한 소개가 성공했다면 선택하지 않은
나머지 근거를 전부 쓰도록 강요하지 않는다. 전달 기억은 최근 두 건의 채택된 공간 근거 선택이며,
이전 생성문·행동·사용자 원문을 포함하지 않는다. 참조 선택은 자연어 의미 검증의 증거가 아니다.

## 현재 강아지 사건

`current_action.build_action_brief`는 현재 장면의 살아 있는 행동핀이 원본 기록과 일치할 때만 열린다.
필수 사건은 실제 기록 참조·반려견 타입·지정 pet_id/이름·행동 코드·시각/위치를 묶는다.
pet_id가 미지정이면 이름으로 특정 강아지를 추정하지 않는다. `excretion`을 소변/대변으로 세분화하지 않는다.
반복 핀은 기록 참조가 다르므로 별개 사건으로 남는다.

현재 피복·도로명·동시점 걸음/동선 모양만 `for_event_id`로 이 사건에 붙는다. 이전 장소·이전 행동·
보호자/동행 소개 목록은 행동 계약의 입력 필드가 아니다. 기기 이동은 함께한 산책의 맥락이며
반려견 행동의 원인·시작/종료 구간으로 바꾸지 않는다. 기존 현재 핀 이동 추출 함수를 재사용한다.

## 산책 시간과 표시 순서

`walk_phase.scene_positions`는 실제 원본의 시작·종료와 선택된 장면 시각을 묶는다.
선택 장면 번호/개수와 실제 출발·종료 여부는 독립이다. 단계 값은 `departure`, `in_progress`, `closing`.
초기 `session-windows-v1` 정책은 시작/끝 120초다. 짧은 산책에서 겹치면 가까운 시간 경계를
선택하고, 정중앙은 `in_progress`다. 정책과 시간은 내부 입력에 고정되며 문장 템플릿은 없다.
시작·종료와 정확히 같은지 여부는 별도 값이고, 단계 자체는 귀가·도착·도로 통과를 뜻하지 않는다.
