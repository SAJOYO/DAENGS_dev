# 두 진입점, 하나의 검색

| | 챗봇 진입 | 메뉴 진입 |
|---|---|---|
| 입력 | 자연어 | 필터 UI |
| 위치 | 대화 시점 현위치 1회 | 지도 드래그 시 재검색 |
| 출력 | 상위 몇 개 + 지도 카드 | 마커 전체 + 리스트 |
| LLM | 질의 파싱 | 안 씀 |

뒤는 같은 `search()`. LLM은 파라미터를 만들 뿐 병원 정보를 생성하지 않는다.
챗봇 카드의 "지도에서 보기" = 메뉴 화면으로 딥링크(필터 채워진 채). 지도 코드 한 벌, 검색 API 한 벌.
