# 네오 채소 도감 (holographic card demo)

강아지 네오가 채소가 된 트레이딩 카드 12장을, 포켓몬 카드 게임 포켓처럼 기울이고
반짝이게 만든 데모입니다.

```
http://localhost:3000/neo-hologram/index.html
```

**`/neo-hologram/` 만 치면 404 입니다.** Next 가 `public/` 안의 디렉터리 인덱스를
잡아 주지 않아서, `index.html` 까지 붙여야 합니다.

## 이 폴더의 전제: 폴더 하나로 자족한다

**빌드 단계가 없습니다.** `public/` 안의 정적 파일이라 그대로 서빙되고, 고치면
새로고침으로 끝납니다. 번들러도 `node_modules` 도 안 씁니다 — 그래서 npm 패키지를
`import` 할 수 없고, 필요한 건 `vendor/` 로 복사해 옵니다.

이 전제를 깨는 변경(빌드 도입, 번들러 도입)은 이 폴더의 성격을 바꾸는 결정이라
`docs/decisions.md` 에 남기고 하세요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 껍데기. **CSS 링크 순서가 중요합니다** (아래 참고) |
| `cards.mjs` | 카드 12장의 데이터. 그림 속 인쇄 문구를 그대로 옮긴 것 |
| `main.js` | 도감 그리드 · 확대 뷰 · 기울기 입력(포인터/키보드) |
| `style.css` | 카드 기본 모양. 프레임 · 그림자 · 자체 포일 · 글레어 |
| `rarity.css` | 레어도별 표면. **cards-css 로 가는 다리**가 여기 있습니다 |
| `immersive.css` / `.mjs` | No.01 전용. 꾹 누르면 카드 안으로 들어가는 별개의 뷰 |
| `vendor/cards-css/` | `@kongyo2/cards-css` 0.5.0 (MIT) 의 포일 CSS. **원본 그대로** |
| `art/` | 카드 그림 (webp). 원본 PNG 는 `tools/art-src/` (gitignore) |

## 카드와 포일

레어도는 등급표가 아니라 **연출 방식**입니다. "위로 갈수록 더 반짝이게" 가 아니라
카드마다 서로 다른 렌더링 기법을 씁니다 — 기법이 겹치면 시험할 게 없어지기 때문입니다.
**12장 전부 다릅니다.**

| No. | 카드 | 포일 | 기법 | 출처 |
| --- | --- | --- | --- | --- |
| 01 | Cabbage | `immersive` | 꾹 누르면 카드 안으로 들어간다 | **우리 것** |
| 02 | Pepper | `prism` | 무지개가 각도로 쪼개지는 분광 | cards-css |
| 03 | Eggplant | `crystal` | 결정 패싯. 면마다 따로 꺾인다 | cards-css |
| 04 | Carrot | `gold` | 금박 (데모의 GOLD SECRET) | cards-css |
| 05 | Danhobak | `oilslick` | 어두운 기름막 무지개 | cards-css |
| 06 | Mushroom | `sunburst` | 중심에서 뻗는 광선 | cards-css |
| 07 | Broccoli | `holo` | 무지개 밴드 + 세로 스캔라인 | cards-css |
| 08 | Cucumber | `reverse` | 가운데를 죽이고 가장자리를 살리는 역전 폴오프 | cards-css |
| 09 | Spinach | `aurora` | 넓고 부드러운 색 띠 | cards-css |
| 10 | Sweet Potato | `cosmos` | 성운 결 | cards-css |
| 11 | Tomato | `mosaic` | 격자로 잘린 타일. 유일하게 무늬가 기하학 | cards-css |
| 12 | Lettuce | `metal` | 세로로 긁힌 브러시드 결. 명도만 오르내리는 이방성 | cards-css |

`cards.mjs` 의 `rarity` 값이 곧 cards-css 의 포일 이름이고, 그대로 DOM 의
`data-effect` 가 됩니다.

### 안 쓰는 포일

cards-css 는 14종입니다. 나머지 셋은 이렇습니다.

| 포일 | 왜 안 쓰나 |
| --- | --- |
| `radiant` | **쓸 수 있는데 안 골랐습니다.** `reverse` 와 느낌이 겹쳐서 11번에서 뺐습니다 |
| `glitter` · `rainbow` | **CSS 만으로는 못 씁니다.** 반짝이 텍스처(`--glitter`)를 원본 JS 가 런타임에 만들어 넣습니다. 우리는 JS 를 안 가져왔습니다 |

`glitter` / `rainbow` 를 살리려면 `--glitter` 에 CSS 로 만든 반짝이를 넣어 주면 됩니다 —
`gold` 의 `--grain` 을 그렇게 처리해 놨으니 그걸 따라 하면 됩니다.

> `mosaic` 은 `--glittersize` 를 쓰는데 **이건 텍스처가 아니라 그냥 길이**입니다.
> 이름이 비슷해서 한 번 잘못 걸렀던 적이 있습니다.

## cards-css 는 어떻게 붙어 있나

원본 파일을 **한 글자도 고치지 않습니다.** 버전을 올릴 때 통째로 갈아끼우려고 그렇게
뒀습니다. 대신 `rarity.css` 의 '다리' 블록이 세 가지를 맞춰 줍니다.

1. **이름** — 우리 `--mouse-x` 를 저쪽 `--pointer-x` 로 넘깁니다
2. **배치** — 저쪽은 grid 로 겹치는 구조인데 우리는 `absolute` 라, `::before`/`::after`
   겹침을 직접 만들어 줍니다
3. **기본값** — `base.css` 에 있던 값 중 우리가 쓰는 포일이 실제로 읽는 것만 옮겨 적었습니다

선택자를 바꾸는 대신 `main.js` 가 우리 요소에 그쪽 클래스명을 얹습니다
(`.stage` → `.holo-card` + `data-effect`, `.foil` → `.holo-card__shine`,
`.glare` → `.holo-card__glare`).

**`base.css`(9.5KB)는 가져오면 안 됩니다.** 포일뿐 아니라 기울기 · 그림자 · 카드
뒤집기까지 들어 있어서 `style.css` 의 `.stage` / `.card` 와 정면으로 부딪힙니다.

**`index.html` 의 링크 순서가 중요합니다.** vendor 링크가 `rarity.css` 보다 **뒤에**
와야 합니다. 특정도가 똑같아서(0,3,0) 순서로만 갈립니다.

## 세기 조정 — 얹으면 얼굴이 날아갑니다

**cards-css 의 기본값이 틀린 게 아니라 원화가 다른 것입니다.** 그쪽 데모 카드는 어두운
벡터 그림입니다. 우리 원화는 정반대로 이미 홀로그램이 인쇄돼 있어 바탕부터 밝고,
**주인공이 흰 강아지**입니다. 포일 대부분이 `color-dodge`(gold 만 `hard-light`)라
밝은 데에 얹으면 흰색으로 클리핑되고, 그러면 제일 먼저 사라지는 게 얼굴입니다.

vendor 파일은 건드리지 말고 `rarity.css` 아래쪽에서 `--hc-*` 로만 누르세요.
`.foil` 의 `opacity` 는 `::before`/`::after` 까지 한 덩어리로 내리므로, 포일 파일 안에
박혀 있는 개별 `opacity` 도 이 한 손잡이에 같이 딸려 옵니다.

| 손잡이 | 언제 |
| --- | --- |
| `--hc-brightness` | 기본. 닷지가 흰색으로 넘어가는 걸 막습니다 |
| `--hc-shine-opacity` | 원화와 섞는 비율. **무늬 안쪽 대비는 안 건드립니다** |
| `--hc-saturate` | 색이 너무 뜰 때 |
| `--hc-glare-opacity` | 하이라이트만 따로 |

**무늬가 구조인 포일은 `brightness` 로 누르면 안 됩니다.** `mosaic` 의 격자와 `metal` 의
세로 결은 무늬끼리의 대비로 생기는 거라, 밝기를 내리면 색이 돌아오는 대신 무늬가 같이
뭉개집니다 — 그러면 그 티어를 고른 이유가 없어집니다. 11번은 `opacity` 로만 누르고,
12번은 `opacity` 를 주로 씁니다.

`hard-light` 포일(`gold` · `metal`)은 `brightness` 를 내리면 blend 가 곱하기 쪽으로
넘어가 탁해집니다. 이 둘도 `opacity` 가 주 손잡이입니다.

지금 눌러 둔 카드는 04 `gold` · 06 `sunburst` · 09 `aurora` · 11 `mosaic` · 12 `metal`
다섯입니다.
**나머지는 일부러 원본 값 그대로입니다** — "얘넨 왜 안 눌렀지" 하고 채워 넣지 마세요.
각 카드의 이유는 `rarity.css` 주석에 날짜와 함께 적혀 있습니다.

**원화를 갈아끼우면 숫자를 다시 봐야 합니다.** 배경이 어두운 원화가 오면 눌러 둔 만큼
심심해집니다.

## 카드 한 장 추가하기

1. 원본 PNG 를 `tools/art-src/` 에 두고, **webp 로 변환**해서 `art/` 에 넣습니다.
   높이 1125, 품질 82 가 지금 쓰는 값입니다 (장당 150~250KB). 크롭하지 않습니다 —
   비율이 갈리는 건 괜찮고, 늘이는 게 안 됩니다
2. `cards.mjs` 에 항목을 추가합니다. `w`/`h` 는 **webp 의 실제 픽셀**을 적습니다
   (CSS 가 이 값으로 카드마다 `aspect-ratio` 를 잡습니다)
3. 텍스트는 **그림에 인쇄된 문구를 그대로** 옮깁니다. 안 찍혀 있으면 지어내지 말고
   비웁니다 (No.11 Tomato 는 스탯 라벨이 없어서 비어 있습니다)
4. 포일을 고르고, 그 이름이 `CARDS_CSS_EFFECTS` 에 있는지 확인합니다

## 포일 바꾸기 / 추가하기

**세 군데가 맞아야 화면에 나옵니다.** 하나라도 빠지면 조용히 기본 풀아트로 보입니다.

1. `vendor/cards-css/<이름>.css` 파일이 있을 것
2. `index.html` 에 링크가 있을 것 (rarity.css 뒤에)
3. `cards.mjs` 의 `CARDS_CSS_EFFECTS` 에 이름이 있을 것

새 파일을 vendor 에 넣을 땐 **그 파일이 무엇을 읽는지 먼저 확인하세요.**

```bash
grep -oh 'var(--[a-z0-9-]*' vendor/cards-css/<이름>.css | sort -u
```

다리 블록에 없는 변수를 fallback 없이 읽으면, 그 선언이 **통째로** 죽습니다 (CSS 는
`var()` 가 계산 단계에서 무효가 되면 속성 하나가 아니라 선언 전체를 버립니다).
무늬가 일부만 안 나오는 게 아니라 그 레이어가 통째로 사라지므로, 눈으로만 보면
"원래 이런 효과인가 보다" 하고 넘어가기 쉽습니다.

## 다시 밟지 말 것

- **`--rotate-x` / `--rotate-y` 는 양쪽에 같은 이름으로 있습니다.** 우리 것은 카드를
  실제로 돌리는 각도(deg)이고 저쪽 것은 `.holo-card__rotator` 용입니다. 지금 고른
  포일들은 안 읽지만, vendor 에 파일을 더 넣을 땐 확인하세요. 읽으면 카드가 두 번 돕니다
- **`--tilt-x` / `--tilt-y` 에 우리 `--rotate-x/y` 를 잇지 마세요.** 저쪽은 단위 없는
  맨숫자입니다. deg 를 넣으면 계산이 무효가 되면서 무늬가 통째로 사라집니다
- **마스크와 같은 요소에 `filter` 를 걸면 안 됩니다.** filter 가 mask 보다 먼저
  적용돼서, 오려낸 모양이 아니라 실루엣 전체가 그림자를 집니다. `drop-shadow` 는
  한 겹 바깥 div 에
- **그라디언트 정지점은 커지는 순서여야 합니다.** `r2 < r1` 이면 뒤 값이 `r1` 으로
  클램프돼서 부드러운 페이드가 아니라 하드컷이 됩니다
- **`blur(0px)` 도 공짜가 아닙니다.** 값이 0 이어도 요소마다 필터용 렌더 표면이 생깁니다
- **`will-change` 를 카드 전부에 걸지 마세요.** 활성 카드에만 겁니다 — 12장에 걸면
  레이어가 12개 생깁니다

## 아직 안 닫힌 것

- **이머시브 진입 순간 600KB 레이스.** 에셋에 선로딩이 없어서 꾹 누른 그 순간 처음
  받습니다. 느린 망에서는 틀만 녹고 빈 텃밭이 뜹니다. 꾹 누르는 520ms 를 선로딩에
  쓰는 게 자연스러운 자리입니다
- **겉잎이 아직 진짜 레이어가 아닙니다.** 속과 같은 픽셀을 고리로 오려 쓰고 있어서,
  비켜도 새로 드러나는 게 없습니다. 겹마다 그린 원화가 오면 `.dio-rind` 의 마스크만
  빼고 `scene.shells` 에 `src` 를 넣으면 됩니다
- **자이로 기울기.** 지금은 포인터로만 기웁니다. 받는 변수는 이미 다 있고, iOS 의
  `DeviceOrientationEvent.requestPermission()` 은 사용자 제스처 안에서 불려야 하는데
  이머시브 진입용 꾹 누르기 520ms 가 이미 그 제스처입니다
